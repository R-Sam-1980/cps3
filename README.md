# iPad 版 RetroArch 使用的 CPS3 街机游戏列表资源


## 分支：ra-playlist-ipad

- 所有的图片文件从 ra-playlist-windows 合并过来
- 所有的游戏列表文件（.lpl 格式）使用 python 脚本生成


## ROM 文件

游戏列表文件里配置的 ROM 文件所在目录：~/Documents/RetroArch/roms/fbn/cps3

## 遮罩

overlays\cps3 文件夹里的遮罩文件命名规则：
- 以游戏 ROM 文件命名
- 一个游戏有多个遮罩的时候，以后缀 -a、-b、-c、-d 加以区分
